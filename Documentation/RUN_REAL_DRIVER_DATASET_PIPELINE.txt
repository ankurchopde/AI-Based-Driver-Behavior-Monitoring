SOFTWARE REQUIRED
-----------------
MATLAB with basic file/video/image functionality.

Python 3.x available from Windows PATH.

Python packages:
    numpy
    opencv-python

Install once from Command Prompt:
    py -m pip install numpy opencv-python

If "py" is unavailable:
    python -m pip install numpy opencv-python


EXECUTION
---------
STEP 1
------
Confirm the two pipeline files are in:

D:\Academics\TY_SEM1\AE\AI based Driver Detector\

STEP 2
------
Open MATLAB.

STEP 3
------
Set MATLAB Current Folder to:

D:\Academics\TY_SEM1\AE\AI based Driver Detector\

STEP 4
------
Run:

MASTER_DRIVER_DATASET_PIPELINE

STEP 5
------
MATLAB automatically calls:

prepare_real_driver_datasets.py

The Python part performs dataset preparation:

S1:
Real UTA-RLDD videos
        ->
genuine frames

S2:
Real State Farm images
        ->
organized genuine images + labels

S3:
CASIA-WebFace train.rec
        ->
genuine face images

STEP 6
------
MATLAB reads the generated manifests and creates:

dataset\processed_real\manifests\

    section1_manifest.csv
    section2_manifest.csv
    section3_manifest.csv
    master_manifest.csv

STEP 7
------
MATLAB creates:

dataset\matlab_dataset_results\

    Section1_Drowsiness_Results.csv
    Section2_Distraction_Results.csv
    Section3_Identification_Results.csv
    Driver_Monitoring_Master_Dataset.csv

and PNG graphs plus:

    Dataset_Processing_Summary.txt


IMPORTANT
---------
The Prediction columns are intentionally NaN in this preparation stage.

DO NOT replace them manually with guessed values.

The next stage is to connect the actual project AI algorithms:
    - drowsiness
    - distraction/attention
    - driver identification

Those algorithms should populate Prediction and measured processing-time/FPS fields.


TROUBLESHOOTING
---------------
If MATLAB says Python is not found:
    In Command Prompt run:
        where python
        where py

If packages are missing:
        py -m pip install numpy opencv-python

If S1 says no videos:
    Check:
    dataset\section1_drowsiness\

If S2 says no images:
    Check:
    dataset\section2_distraction\archive\imgs\train\

If S3 says train.rec is missing:
    Check:
    dataset\section3_identification\

The scripts search recursively, so the exact nested level can vary.
