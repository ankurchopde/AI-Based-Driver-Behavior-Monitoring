S3 TEMPORARY PROCESSOR
=======================

Use this when the CASIA train.rec extraction is unavailable.

Dataset location:
D:\Academics\TY_SEM1\AE\AI based Driver Detector\dataset\section3_identification\extracted

Expected:
extracted\
  0\
  1\
  2\
  ...
  14\

Each folder must contain the actual face images.

1. Copy S3_IDENTIFICATION_TEMP_PROCESSOR.m into:
D:\Academics\TY_SEM1\AE\AI based Driver Detector\

2. Open MATLAB.

3. Set Current Folder to:
D:\Academics\TY_SEM1\AE\AI based Driver Detector\

4. Run:
S3_IDENTIFICATION_TEMP_PROCESSOR

The script:
- scans folders 0 through 14
- counts genuine readable images
- uses folder number as identity ground truth
- does not create or duplicate images
- creates S3_Identification_Temp_Results.csv
- creates two graphs
- creates S3_Identification_Temp_Summary.txt

Prediction remains NaN until the real identification algorithm is run.
