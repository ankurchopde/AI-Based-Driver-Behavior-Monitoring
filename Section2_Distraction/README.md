# Section 2: Driver Distraction

## Status
COMPLETE / VALIDATED / FROZEN

## Overview
This section contains the prototype implementation for driver distraction detection. It uses head pose estimation and gaze tracking to determine if the driver's attention is on the road.

## Components
- **Python / MediaPipe**: Extracts head pose and gaze features.
- **MATLAB / Simulink**: Distraction logic and UDP receiver.

**Note:** This is the prototype implementation, not the final Raspberry Pi deployment.
