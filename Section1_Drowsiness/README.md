# Section 1: Driver Drowsiness

## Status
COMPLETE / VALIDATED / FROZEN

## Overview
This section contains the prototype implementation for driver drowsiness detection using MATLAB/Simulink and Python. It monitors the driver's Eye Aspect Ratio (EAR) to determine signs of drowsiness.

## Components
- **Python / MediaPipe**: Extracts facial landmarks and calculates EAR.
- **MATLAB / Simulink**: Implements the drowsiness detection logic based on EAR inputs received via UDP.

**Note:** This is the prototype implementation, not the final Raspberry Pi deployment.
